# 📖 Overview

Converta is a comprehensive file processing platform that combines PDF tools, image utilities, document converters, and AI-powered enhancements into a single seamless experience.

Instead of switching between multiple websites and applications, users can perform everything from PDF editing and document conversion to image enhancement and background removal in one unified workspace.

Designed for students, professionals, businesses, creators, and developers, Converta delivers powerful file management tools while maintaining speed, privacy, and ease of use.

---

# ✨ Features

## 📄 PDF Tools

### Merge PDF

Combine multiple PDF files into a single document while preserving quality and page order.

### Split PDF

Extract specific page ranges or divide documents into multiple PDFs.

### Compress PDF

Reduce file size while maintaining visual quality.

### Remove Pages

Delete unwanted pages from PDF documents.

### Organize PDF

Rearrange, reorder, and structure PDF pages visually.

### Repair PDF

Recover and repair corrupted PDF files.

### OCR PDF

Convert scanned documents into searchable and selectable text.

### Rotate PDF

Rotate individual pages or entire documents.

### Add Watermark

Protect documents with text or image watermarks.

### Add Page Numbers

Automatically insert page numbering into PDFs.

### Crop PDF

Trim and adjust page boundaries.

### Protect PDF

Encrypt PDFs using password protection.

### Unlock PDF

Remove password restrictions from authorized documents.

### Redact PDF

Permanently remove sensitive information.

### Sign PDF

Add digital signatures using drawing, typing, or uploaded signatures.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/thanishkaykb/Converta.git

cd Converta
```

## Install Dependencies

```bash
npm install
```

or

```bash
bun install
```

## Configure Environment Variables

Create a `.env` file:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## Run Development Server

```bash
npm run dev
```
